# DaemonSets

- DaemonSet deploys one replica to each of the available nodes except the node that is tainted. 
- Useful for use cases, such as monitoring agents, logging agents, networking CNIs, etc.

### DaemonSet - Declarative Command

```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: nginx-daemonset
spec:
  selector:
    matchLabels:
      app: nginx-daemon
  template:
    metadata:
      name: nginx
      labels:
        app: nginx-daemon
    spec:
      containers:
        - name: nginx
          image: nginx
          ports:
            - containerPort: 80
```

Verify:

```yaml
kubectl get daemonsets
kubectl get pods -o wide
```
