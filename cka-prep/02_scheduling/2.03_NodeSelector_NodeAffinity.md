# Node Selector

- `nodeSelector` schedules a Pod only on Nodes having matching labels. The Kubernetes scheduler still chooses the actual Node from all matching Nodes.

## Operations of Node Selector

**Label a Node:** `kubectl label node worker1 disktype=ssd`

Apply Node Affinity to Pod

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx
spec:
  nodeSelector:
    disktype: ssd
    workspace: prod     # optional
  containers:
    - name: nginx
      image: nginx
```
- Multiple nodeSelector entries use AND logic.

# Node Affinity

- **Node Affinity** controls which Nodes a Pod can or should run on based on Node labels. It is more flexible than `nodeSelector`. 

## Types of Node Affinity

`IgnoredDuringExecution` means the Pod is not evicted if the Node label changes after scheduling.

- **Required Affinity**: A hard rule. The Pod remains Pending if no Node matches. 

    `requiredDuringSchedulingIgnoredDuringExecution`

- **Preferred Affinity**: A soft rule. Kubernetes prefers matching Nodes but may schedule the Pod elsewhere.

    `preferredDuringSchedulingIgnoredDuringExecution`

## Operation of Node Affinity

**Label a Node:** `kubectl label node worker1 disktype=ssd`

Apply Node Affinity to Pod

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: redis
spec:
  affinity:
    nodeAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
        nodeSelectorTerms:
          - matchExpressions:
              - key: disktype
                operator: In
                values:
                  - ssd
  containers:
    - name: redis
      image: redis
```

## Operators in Node Affinity

| Operator       | Meaning                                   |
| -------------- | ----------------------------------------- |
| `In`           | Value must match one of the listed values |
| `NotIn`        | Value must not match listed values        |
| `Exists`       | Label key must exist                      |
| `DoesNotExist` | Label key must not exist                  |
| `Gt`           | Numeric value must be greater             |
| `Lt`           | Numeric value must be smaller             |

## Others on Node Affinity

- **Important Facts**

    ```text
    Expressions inside one nodeSelectorTerm = AND
    Multiple nodeSelectorTerms = OR
    ```

- **For a Deployment, place affinity under**: `spec.template.spec.affinity`

- Node affinity attracts Pods to Nodes, while taints repel Pods from Nodes.
