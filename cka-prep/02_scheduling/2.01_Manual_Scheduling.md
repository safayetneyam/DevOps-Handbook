# Manual Scheduling

- Manual scheduling assigns a Pod directly to a specific node using ```spec.nodeName```, bypassing the kube-scheduler. It is useful for testing, special node placement, or when the scheduler is unavailable, but the Pod may fail if the selected node lacks resources.

### Manual Scheduling - Declarative Approach

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
spec:
  nodeName: cka-cluster-worker
  containers:
    - name: nginx
      image: nginx
```

```bash
kubectl apply -f pod.yaml
kubectl get pods -o wide
```

The Pod will run only on ```cka-cluster-worker```.
