## Kubernetes API Versions

| API Version | API Group | Common Components / Resources |
|---|---|---|
| `v1` | Core (Legacy) | Pods, Services, ConfigMaps, Secrets, Namespaces |
| `apps/v1` | apps | Deployments, StatefulSets, DaemonSets, ReplicaSets |
| `batch/v1` | batch | Jobs, CronJobs |
| `networking.k8s.io/v1` | networking.k8s.io | Ingress, NetworkPolicies |
